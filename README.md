# Get Local Hawaiʻi

Directory of local Hawaiʻi vendors (lei stands, farmers markets, fish, produce)
where every listing shows when it was last verified and "open now" is computed,
never hardcoded.

Next.js (App Router, TypeScript, Tailwind) on Supabase, deployed on Vercel.

- `npm run dev` to run locally, `npm test` for unit tests.
- `docs/BUILD_SPEC.md` is the build spec, `docs/STATUS.md` is the current state.
